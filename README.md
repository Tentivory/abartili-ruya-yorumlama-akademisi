# Abartılı Rüya Yorumlama Akademisi

## Resmi Duyuru

Bu repository, insanlık tarihinin en önemli bilimsel atılımlarından birini temsil etmektedir.  
**Abartılı Rüya Yorumlama Akademisi**, rüyaları yalnızca yorumlamakla kalmaz; onları **kuantum dolanıklık**, **Osmanlı arşivleri**, **varoluşsal kriz** ve **rastgele seçilmiş akademik jargon** ile yeniden yazar.

### Neden Bu Proje Hayati Öneme Sahiptir?

- Klasik rüya yorumları yetersizdir.
- Freud yetersiz kalmıştır.
- Jung bile bu kadar abartamamıştır.
- Bu sistem, rüyalarınızı %147 oranında daha anlamlı (ve tamamen uydurma) hale getirir.

### Nasıl Çalışır?

```bash
python ruya_yorumcu.py
```

Program size bir rüya anahtar kelimesi sorar.  
Siz "uçmak", "diş düşmek", "sınav", "kedi" veya "herhangi bir şey" yazarsınız.  
Akademi, size **resmi**, **ciddi** ve **kesinlikle bilimsel** bir yorum sunar.

### Örnek Çıktı (Gerçek Çalışmadan)

> Girdi: uçmak  
> Akademik Yorum:  
> "Bu rüya, bilinçaltınızın yerçekimine karşı yürüttüğü gizli bir diplomatik müzakeredir. Kuantum düzeyinde, atalarınızın 1453'te İstanbul'u fethetmeden hemen önce gördüğü rüya ile dolanık haldedir. Öneri: Daha fazla baklava yiyin."

### Kurulum

1. Python 3.x yeterlidir (daha eski sürümler de çalışabilir, çünkü zaman görecelidir).
2. Hiçbir kütüphane gerekmez. Saf bilim.
3. İnternet bağlantısı gerekmez. Rüyalar zaten offline'dır.
